# Documents Publics du Client

Ce dossier (`documents/`) est destiné à recevoir les fichiers téléchargeables publics fournis pour le site client (brochures tarifaires PDF, conditions générales de vente, formulaires, etc.).

## Bonnes pratiques :
1. **Nomenclature** : Utilisez des noms de fichiers simples, en minuscules, sans espaces ni caractères spéciaux (ex: `tarifs-2026.pdf`, `brochure-mariage.pdf`).
2. **Poids** : Veillez à compresser les PDF pour le web (< 5 Mo par fichier).
3. **Sécurité** : Aucun document confidentiel (RIB, contrats signés avec données personnelles) ne doit être déposé dans ce dossier public.
