# Site vitrine WebExpresso

Site de présentation de WebExpresso, en plusieurs pages (français, et anglais dans `en/`), avec le questionnaire dans `questionnaire/`.
Les pages publiées sont produites : on modifie `_source/`, puis on reconstruit. Tout est expliqué dans [`_source/LISEZMOI.md`](_source/LISEZMOI.md).
Le questionnaire se modifie dans le dépôt principal (`Phase 1 _ Formulaire/questionnaire/`), jamais ici à la main.
