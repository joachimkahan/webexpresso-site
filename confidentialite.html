Vos données personnelles

Cette page dit quelles informations nous recevons de vous, à quoi elles servent, combien de temps nous les gardons et comment les faire corriger ou effacer. Ce site ne dépose aucun cookie de suivi ni de publicité.

Qui est responsable de vos données

Le responsable de vos données est WebExpresso. Vous pouvez nous joindre à webexpresso.info@gmail.com.

Les données que nous recevons

Ce sont celles que vous nous transmettez vous-même, en remplissant le questionnaire ou en nous écrivant par e-mail :

  • votre nom et votre prénom ;
  • votre adresse électronique ;
  • votre numéro de téléphone, si vous le donnez ;
  • la description de votre activité professionnelle ;
  • vos choix de couleurs ;
  • vos photographies et vos textes.

Dans le questionnaire, seules les réponses marquées « obligatoire » sont nécessaires : sans elles, nous ne pouvons pas préparer votre site. Toutes les autres sont facultatives.

Les photos et vidéos que vous ajoutez dans le questionnaire sont envoyées directement dans un espace de stockage Google Cloud (Google Cloud EMEA Limited, Irlande) situé à Paris, que seul WebExpresso peut ouvrir : personne d'autre ne peut les voir ni les lister. Nous les copions dans le dossier de votre projet, et elles sont effacées de Google Cloud au plus tard 30 jours après leur envoi. Google étant une société américaine, une demande d'accès des autorités des États-Unis ne peut pas être exclue ; un tel transfert est encadré par le cadre de protection des données UE-États-Unis.

Si vous nous donnez plutôt un lien de partage, vos photos et vos documents restent chez le service que vous avez choisi. Nous les téléchargeons pour préparer votre site.

À quoi elles servent

  • étudier votre projet et traiter votre demande gratuite de création de site ;
  • gérer le questionnaire en ligne ;
  • vous faire une proposition et enregistrer la formule que vous choisissez ;
  • créer votre site, si vous acceptez la proposition ;
  • suivre la facturation.

Ce qui nous y autorise : les démarches faites à votre demande avant la commande, puis l'exécution du contrat si vous commandez (article 6.1.b du RGPD, le règlement européen sur la protection des données).

Qui reçoit vos données

Vos données ne sont jamais revendues ni cédées à des tiers. Elles sont traitées de façon confidentielle et circulent chiffrées (chiffrement TLS).

Les réponses au questionnaire sont reçues par WebExpresso seulement. Pour la seule transmission, elles passent par Formspark (Trampoline Software SRL, Belgique), un prestataire technique qui nous envoie le questionnaire par e-mail. Nous le recevons dans une messagerie Gmail (Google).

Formspark stocke les messages dans l'Union européenne (Irlande et Allemagne). Deux de ses sous-traitants sont établis aux États-Unis : Sentry (rapports d'erreur, sous le cadre de protection des données UE-États-Unis) et Mapbox (localisation approximative par l'adresse IP, sous les clauses contractuelles types de la Commission européenne). Les messages sont supprimés de Formspark au plus tard six mois après leur réception ; Formspark garde l'adresse IP de l'expéditeur douze mois. Politique de confidentialité de Formspark.

D'autres prestataires techniques interviennent selon le cas :

  • GitHub Pages (GitHub, Inc., États-Unis) héberge ce site. Il enregistre l'adresse IP des visiteurs dans ses journaux techniques, pour la sécurité du service ;
  • Google Cloud (Google Cloud EMEA Limited, Irlande) reçoit, à Paris, les photos et vidéos ajoutées dans le questionnaire, 30 jours au plus ;
  • Stripe assure le paiement sécurisé en ligne ;
  • GitHub Pages et Firebase servent à l'hébergement des sites des clients et à leur espace privé (l'Espace Pro).

Certains de ces prestataires peuvent traiter les données hors de l'Union européenne. Ces informations sont redonnées dans la partie « Vos données » du questionnaire, au moment où vous répondez.

Combien de temps nous les gardons

  • Si aucun projet ne suit : vos réponses sont supprimées au plus tard 3 ans après votre dernier message.
  • Si nous travaillons ensemble : elles sont gardées le temps du projet, puis archivées pendant les délais légaux. Les données de facturation et les dossiers de livraison sont conservés 10 ans, comme le demande le Code de commerce.

Vos droits

Vous pouvez, à tout moment :

  • consulter les données que nous avons sur vous (droit d'accès) ;
  • les faire corriger (rectification) ;
  • les faire supprimer (effacement) ;
  • demander que leur utilisation soit limitée (limitation) ;
  • vous opposer à leur utilisation (opposition) ;
  • les récupérer, pour les garder ou les confier à un autre prestataire (portabilité).

Pour exercer ces droits, écrivez à webexpresso.info@gmail.com.

Vous pouvez aussi donner des directives sur le sort de vos données après votre décès.

Vous pouvez enfin adresser une réclamation à la CNIL (Commission nationale de l'informatique et des libertés) : www.cnil.fr.

Cookies et mémoire de votre navigateur

Ce site ne dépose aucun cookie de suivi ni de publicité. Il ne charge aucun service de mesure d'audience, aucune police ni aucun autre service venu d'ailleurs : ses polices d'écriture sont hébergées avec lui. Il n'y a donc ni bandeau, ni réglage de cookies.

Une seule chose est gardée dans votre navigateur : le brouillon du questionnaire. Tant que vous n'avez pas envoyé le questionnaire, vos réponses sont gardées seulement dans votre navigateur, sur votre appareil, pour que vous puissiez reprendre plus tard sans rien perdre. Rien ne nous parvient avant l'envoi.

Ce brouillon s'efface de lui-même après l'envoi, ou au bout de 30 jours. Le bouton « Effacer mes réponses » du questionnaire le supprime aussi.

Au moment de l'envoi, le passage par Formspark peut déposer ses propres cookies de fonctionnement.
